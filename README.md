# MHSS Public Calendar

Static public calendar for the MHSS ERP.

Files:
- index.html
- supabaseClient.js
- logo2.png
- vercel.json

The calendar uses the same Supabase project as the ERP:
https://miugvibogwwvkmbhocnw.supabase.co

IMPORTANT:
1. Open supabaseClient.js.
2. Replace PASTE_YOUR_PUBLIC_ANON_OR_PUBLISHABLE_KEY_HERE with the SAME public anon/publishable key used by the ERP.
3. NEVER put a service_role/secret key in this public project.
4. Deploy this repository as a separate Vercel project.
